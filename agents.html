🗺️ 五阶段学习路线

跳到资料 →
01

基础认知：理解 LLM 的能力边界

入门 1–2 周

目标：搞清楚「Agent = LLM + 记忆 + 工具 + 规划」，知道模型能做什么、不能做什么。

关键知识点

  • Token / 上下文窗口 / 采样参数的实际影响
  • Prompt 基础：角色设定、少样本、思维链
  • 为什么需要 Agent：从补全到自主决策
  • 幻觉与不确定性的成因

推荐资料

  • Intro to Large Language Models 视频
  • OpenAI Prompt Engineering Guide 文档
  • LLM Powered Autonomous Agents 博客
02

工具调用：让模型能动手

核心 2–3 周

目标：独立实现一套稳定的工具调用链路，能处理参数校验、超时与失败重试。

关键知识点

  • Function Calling 的参数设计与 JSON Schema 约束
  • MCP 协议：工具如何标准化接入
  • 幂等设计、超时控制、错误回传
  • 结构化输出的可靠提取

推荐资料

  • Function Calling 官方指南 文档
  • MCP 协议规范 规范
  • Function Calling 的十八个坑 本站
03

单 Agent 实战：跑通第一个闭环

核心 3–4 周

目标：用框架搭出一个能查资料、调工具、给结论的 Agent，并配上调试与观测。

关键知识点

  • ReAct 循环：思考 → 行动 → 观察
  • 记忆设计：短期对话 vs 长期知识
  • 接入 RAG 让 Agent 掌握私有知识
  • LangGraph / LlamaIndex 状态机建模

推荐资料

  • ReAct: Synergizing Reasoning and Acting 论文
  • LangGraph 官方文档 文档
  • AgentFlow 项目源码 本站
04

多 Agent 协作：分工与编排

进阶 约 4 周

目标：理解角色分工模式，能设计多角色协作流程并处理失败恢复。

关键知识点

  • Planner-Executor-Critic 等经典模式
  • 任务分解、路由与结果聚合
  • 上下文共享与状态一致性
  • 循环控制、预算控制与兜底

推荐资料

  • Building Effective Agents 指南
  • AutoGen / CrewAI 框架
  • 多 Agent 协作系统实战 本站
05

生产化与评测：从能跑到好用

高阶 持续

目标：让 Agent 在真实流量下稳定、可控、可衡量地工作。

关键知识点

  • 成本与延迟优化：缓存、分级模型、并行
  • 可观测性：Token 级追踪与调用链
  • 安全护栏：注入防护、权限最小化
  • 离线评测集与回归测试

推荐资料

  • RAGAS / AgentBench 评测
  • OpenTelemetry GenAI 语义约定 规范
  • LLM 应用可观测性实践 本站

⚖️ 框架选型建议

编排

需要精确控制流程 → 状态机式框架

当流程有明确节点、分支与重试时，用图结构建模比「让模型自由发挥」可控得多。适合生产环境、需要审计与回溯的场景。

多角色

任务可拆解且角色清晰 → 多 Agent 框架

写作、评审、检索这类可以分角色的任务收益明显；但角色过多会带来上下文开销和不确定性，建议先控制在 2–3 个角色。

轻量

需求简单 → 直接调 API

如果只是固定的几轮调用加工具，手写循环反而更清晰、更好调试。不要为了用框架而用框架。

提醒

先做评测，再谈优化

没有评测集的优化都是盲调。哪怕只有 30 条样本，也能帮你在换模型、改 Prompt 时判断到底变好了还是变差了。
