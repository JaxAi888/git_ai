## 一段开胃代码

学习的第一课，往往是最简单的线性回归。用几行代码感受一下「模型在学什么」：

```python
import numpy as np

# 造一批 y = 2x + 1 的数据
X = np.linspace(0, 10, 100)
y = 2 * X + 1 + np.random.randn(100)

# 最小二乘拟合
w, b = np.polyfit(X, y, 1)
print(f"学到的参数: w={w:.2f}, b={b:.2f}")  # 应接近 2 和 1
```

模型「学习」的本质，就是从数据里把这两个参数 `w` 和 `b` 找出来。后面所有复杂的神经网络，起点都在这里。
